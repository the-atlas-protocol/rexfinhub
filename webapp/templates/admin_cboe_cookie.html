Rotate

Pasting sessionid=<value> or the full Cookie: header is fine — the server extracts the token. After submit: cookie is written to VPS config/.env, a live probe runs against AAPL, and the recovery sweep is dispatched in the background if the probe succeeds.
Where do I find the sessionid?
  1. Open cboe.com/symbols/ in a logged-in browser.
  2. Open devtools (F12) → Application tab → Cookies → https://www.cboe.com.
  3. Find the sessionid row (NOT csrftoken, NOT __cf_bm) and copy the Value.
  4. Paste here. Submit.
